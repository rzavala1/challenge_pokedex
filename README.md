# React Native Challenge Pokedex
Este es un ejemplo del uso de el API [https://pokeapi.co/](https://pokeapi.co/)

## Prerrequisitos

 - Node.js  14
 - npm
 - Watchman
 - JDK 15
 - Android Studio and Android SDK

## Uso
1. Para hacer una prueba debe de ubicarse dentro de la carpeta del proyecto con una consola del sistema operativo.
 2. Debe de descargar las dependencias necesarias con el comando :
**npm install**
2. Para ejecutar el proyecto se debe de usar el siguiente comando para aplicación Android:
**npx react-native run-android**
